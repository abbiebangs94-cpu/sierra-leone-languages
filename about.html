About the project

A starting point for learning Sierra Leonean languages

This project aims to celebrate, preserve, and introduce languages spoken across Sierra Leone. It provides a place for learners to discover basic vocabulary, translations, meanings, and pronunciation.

Purpose

Connect learners with meaningful language examples and cultural context.

Audience

Support learners, families, and students who want to explore Sierra Leonean languages.
