# Sierra Leone Languages

This repository contains the semester project prototype for **Sierra Leone Languages**, a web experience that introduces and explores selected Sierra Leonean languages.

## Midpoint Project Checkpoint

### Project direction

- **Primary user:** A learner who wants to discover basic words and meanings in Sierra Leonean languages.
- **Important user experience:** The user should be able to search for a word, select a language, review its translation and meaning, and listen to a browser-generated pronunciation.
- **Current prototype support:** The homepage provides the search, language selector, result cards, and Listen controls.

### Project structure

- `index.html` — homepage with accessible navigation, project information, image, and language search.
- `languages.html` — meaningful language overview page with profiles for Krio, Limba, and Temne.
- `styles.css` — external visual design and responsive layout.
- `app.js` — language data, search filtering, and browser speech functionality.
- `image/image.png` — uploaded project image displayed beside the hero content.

### Design decisions

- The green and light-grey palette was selected to communicate culture, learning, and a calm educational experience.
- The hero uses a two-column layout so the uploaded image remains visible beside the project introduction.
- The search results use consistent cards, clear labels, and keyboard-accessible buttons.
- The layout changes to a single column on smaller screens.

### Next development priorities

1. Add more accurate, verified vocabulary and pronunciation.
2. Improve the language-specific speech experience and add clear source attribution.

> This is an intermediate prototype, not a completed product. The final project will continue to add content and functionality.
